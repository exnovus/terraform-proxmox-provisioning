# Code of Conduct

## Expected Behavior

- Treat contributors and users with technical and professional respect.
- Discuss changes with verifiable arguments and a clear focus on the repository.
- Accept review, correction, and technical disagreement without personal attacks.

## Unacceptable Behavior

- harassment, insults, or abusive behavior
- publishing secrets, credentials, or private third-party data
- aggressive, dismissive, or off-topic discussions
- using the project to expose or ridicule mistakes made by other contributors

## Enforcement

Maintainers may edit, hide, or remove content that violates these rules, and may also limit participation from repeat offenders.

## Scope

This policy applies to issues, pull requests, discussions, reviews, and any official channel associated with the project.
